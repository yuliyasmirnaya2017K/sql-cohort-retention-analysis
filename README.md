# Оцінка утримання користувачів (Retention Rate) методами Google Sheets та SQL на основі когортного аналізу (Cohort Analysis)

## Мета проєкту
Провести комплексний когортний аналіз для оцінки показників утримання користувачів (Retention Rate), дослідити різницю в поведінці клієнтів, залучених органічно та через промо-акції, а також сформувати стратегічні рекомендації для оптимізації маркетингового бюджету.

## Інструменти та структура даних
* SQL: Вивантаження, очищення та попереднє групування даних.
* Google Sheets: Побудова зведених таблиць (Pivot Tables), розрахунок відсоткових матриць Retention Rate та візуалізація за допомогою динамічного умовного форматування.

**Структура вхідних даних для аналізу:**
* promo_signup_flag — маркер типу залучення користувача (0 — органіка, 1 — промо)
* cohort_month — місяць реєстрації користувача (старт когорти)
* month_offset — індекс місяця життя когорти (від 0 до 5)
* users_total — кількість активних користувачів у поточному періоді

## Основні висновки та бізнес-рекомендації (На основі аналізу)
* Поведінка органічних користувачів: Демонструють стабільний рівень утримання (Retention Rate) протягом усього аналізованого періоду (до 5 місяців offset). Вони формують найбільш якісну, лояльну та прогнозовану клієнтську базу компанії.
* Поведінка промо-користувачів: Мають високий початковий показатель залучення (сплеск на 0-му місяці), проте стрімко втрачають активність та залишають сервіс уже з першого місяця життя когорти.
* Рекомендації для бізнесу: Розглянути та вдосконалити внутрішні механізми утримання для клієнтів, які приходять через акції. Оптимізувати маркетингові витрати, перерозподіливши частину бюджету з неефективних промо-кампаній на користь каналів, що генерують стабільне органічне залучення.
